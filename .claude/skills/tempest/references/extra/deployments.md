# Deployments

**Source:** `vendor/tempest/framework/docs/5-extra-topics/03-deployments.md`

## Requirements

PHP 8.4+, Composer. Optional: Bun/Node for frontend. Dedicated server with SSH recommended.

## Deploy script

```sh deploy.sh
#!/bin/bash
. /home/user/.bashrc

# Dependencies
composer install --no-dev
bun install

# Tempest
php tempest cache:clear --force --internal --all
php tempest discovery:generate
php tempest migrate:up --force
php tempest static:clean --force
bun run build
php tempest static:generate --allow-dead-links --verbose=true
```

## Initial server setup `.env`

```env .env
# Generated by `tempest key:generate`
SIGNING_KEY=...

ENVIRONMENT=production
BASE_URI=https://example.com

# Enable all caches in production
INTERNAL_CACHES=true
DISCOVERY_CACHE=true

# Set PHP path if using Tempest frontend scaffolding
PHP_EXECUTABLE_PATH=/usr/bin/php8.4
```

One-time setup:
```sh
php tempest key:generate
```

## `.tempest` directory

Must be writable by web server. Contains discovery cache, view cache, debug logs, sessions.

## Scheduler

Add one cron entry:
```
0 * * * * user /path/to/tempest schedule:run
```

## This project's deploy

See `deploy.sh` in repo root. Uses Docker:
- `Dockerfile`: build (Composer + Node), app (php-fpm), web (nginx) stages
- `docker-compose.yml`: `app:9000` → nginx
- `docker/php/entrypoint.sh`: runs `cache:clear` + `discovery:generate` on every boot
